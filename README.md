# OBX — Readiness

Three browser-based diagnostics for outcome-based contracting: Outcome Readiness Assessment, KPI Contractability Test, and Data & Telemetry Baseline Check.

Standalone version of the app running at [luisprato.com](https://www.luisprato.com). Strictly black-and-white, React 18 + Vite + TypeScript + Tailwind CSS.

All three tools run entirely in the browser — no answer is ever sent anywhere. Routes: `/assessment`, `/kpi-contractability-test`, `/data-telemetry`.

## Run locally

```bash
npm install
npm run dev
```

Then open the printed local URL. No accounts, keys, or backend required.

## Build

```bash
npm run build
npm run preview
```
